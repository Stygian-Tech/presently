# Presently app icon

`Presently-AppIcon-Master.png` is the full-color source artwork. It keeps the
camera-bloom and sparkle within the central adaptive-icon safe area.

Platform outputs:

- iOS uses full-color universal and dark artwork plus a single-color tinted
  appearance in `Assets.xcassets/AppIcon.appiconset`.
- Android uses density-specific legacy icons, separate adaptive foreground and
  background layers, and a monochrome layer for Material You themed icons.

The monochrome and foreground artwork are derived from the same cream-colored
glyph so the silhouette stays consistent across platforms.
